# Ansh Kumar — Personal Portfolio

A personal brand portfolio website for **Ansh Kumar**, a technology builder interested in AI, automation, software development, and digital products.

## 🎨 Design Identity
- **Background**: `#090B0A` (Deep Black)
- **Highlights & Accents**: `#B7FF35` (Lime Green)
- **Surfaces & Typography**: `#F5F7F2` (Clean White)
- **Typography**: Space Grotesk (Headings) & Inter (Body)

## ⚡ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Modern CSS variables & tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Forms**: Formspree integration with fallback error handling

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
